# NOCTILUCA — Digital Observatory

A multi-page experimental web experience built from a blank repository.

## Pages
- `index.html` — observatory entrance
- `archive.html` — searchable/filterable archive
- `lab.html` — interactive parametric field
- `journal.html` — long-form editorial note
- `404.html` — graceful fallback

## Principles
No account, no tracking, local theme preference only, responsive layouts, keyboard-friendly controls, reduced-motion support.

## Deploy
Static files are ready for GitHub Pages.
