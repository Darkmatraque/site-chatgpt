# Darkmatraque — Digital Lab

A deliberately opinionated personal lab / portfolio.

The site treats the portfolio as a digital laboratory rather than a template: editorial typography, technical UI details, project experiments and small interactive tools.

## Included

- Responsive layout
- Project filtering and detail dialogs
- Command palette with ⌘/Ctrl + K
- Keyboard shortcuts and random discovery
- Custom cursor on fine pointers
- Live local time and rotating status signal
- Accessible focus states
- Zero build step: plain HTML, CSS and JavaScript

## Deploy

The repository is ready for GitHub Pages. Serve the root directory as-is.
